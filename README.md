# KargboChat

**Connect. Share. Be heard.**

Responsive React + Vite messaging interface starter.

## Run
- `npm install`
- `npm run dev`

## Current status
This is a frontend demo. Messages are kept only in browser memory and are not delivered to other users or saved online. Supabase authentication, database, realtime messaging, and storage must still be configured. Never expose a Supabase service-role key in frontend code.
